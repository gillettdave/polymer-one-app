PolyOne: The Unified Growth & XP Bot for the Polymer Community

Track Polymer’s growth, reward contributors, and turn on-chain metrics into an interactive community experience.

What is PolyOne?

PolyOne is an all-in-one Discord bot built for the Polymer ecosystem. It connects on-chain analytics, community content, and learning programs into a single XP-driven experience.

Key Features

  • Live metrics updates from Polymer's analytics APIs
  • Milestone celebrations each time total volume crosses a new 0.1B threshold
  • Top-10 transaction alerts when new high-value transactions appear
  • Unified XP system for tweets, quizzes, and more
  • AI-powered tweet grading using a Polymer-specific rubric
  • Volume counter channel that shows current volume and 24h change

How the XP System Works

Every action that should earn XP is logged as an event in a Google Sheet. A separate totals sheet aggregates XP per user, making it easy to run leaderboards, campaigns, or ambassador programs on top.

How to Get Started

  1. Invite the bot to your Discord server.
  2. Connect it to your Google Sheets via a service account.
  3. Configure channel IDs and API keys using a .env file.
  4. Run the bot and let the community start earning XP.
